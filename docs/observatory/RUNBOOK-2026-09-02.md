## Corrections to earlier reporting

Recorded because the same mistakes are easy to repeat.

- **"484 calls" was not the day.** It was 715. The DRS line runs in a separate database
  and nothing joins the two; a day's work for this practice has never been countable in
  one place.
- **The DRS line is not "Sage" in the sense the docs use.** 74 of the 75 calls that
  reached an agent ran on the `scheduling-core` state machine with Grok as voice. The
  OpenAI Sage runtime handled **one** call all day. What outperforms the answering
  service on repetition 20-to-1 is a deterministic state machine, not a better-prompted
  LLM — which changes what "copy the DRS line" would mean.
- **"231 DRS calls" overstates the conversational surface.** 156 never reached an agent.
- **Interruption is not an inbound problem.** Outbound 18 of 33 calls, inbound 25 of 41.
- **`detected_language` is not dead.** It is written on the one legacy-Sage call, which
  makes it a clean lane marker rather than a dead column.
- **A transcript parser that split on newlines and kept lines beginning `AGENT:` dropped
  every continuation line** — 1.7% of all agent speech, and disproportionately the
  closing promises and the ticket numbers. It is why a first pass reported zero
  fabricated ticket numbers when one existed. Use a parser that gives each turn its
  continuation lines.
- **A probe for "claimed to have the record, then asked anyway" fired on the agent
  confirming a value back to the caller** — correct behaviour. Dropped rather than
  reported as 62 findings.

## Limits of this analysis

- **170 of 484 answering-service calls have no tool telemetry.** Every per-tool figure is
  over the 314 that do, and on 37 of the 75 `AS-04` losses the cause genuinely cannot be
  established.
- **This repository's history starts at its import**, `64da94c`, 2026-08-18, 518 files.
  "Introduced at import" means this repo holds no earlier record — not that the code was
  written that day. The ticketing-app and 5Star dates are real history.
- **DRS transcripts exist for 72 of 231 calls.** Conversation-level figures are over those.
- **Quality scores carry two known grader bugs** inflating critical errors by roughly 28%.
- **"Spanish present" is a keyword probe**, not language detection.
- **No code was changed to produce this.** All three repositories were read only.
