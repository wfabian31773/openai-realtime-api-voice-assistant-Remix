- [Input transcription](transcription-config.md) — all four call sites go through `config/transcription.ts`. The accept payload used to hard-default `language:'en'`, force-decoding every Spanish caller who didn't press 4 and garbling the names every identity gate keys on. Send a language only when the call established one. Default is now `gpt-live-transcribe` (adds `languages`/`keywords`/`prompt`); roll back with `TRANSCRIPTION_MODEL=gpt-4o-mini-transcribe`, env only.

Covers `appointment_reference_unknown` and the `identity_required` catch-22 on `sage_handoff`.
- [SIP recovery vs deliberate hangup](sip-recovery-vs-deliberate-hangup.md) — OpenAI /hangup ends only the AI leg; deliberate hangups must markCallConcluded (on success only) or SIP recovery transfers finished calls to the operator.
- [Zombie calls / dead air](zombie-calls-dead-air.md) — the SIP max-duration timer is cleared once connected and the DB reconciler ignores `completed` rows, so a silent connected session ran to the per-agent cap (1,138 calls, ~143h). `deadAirWatchdog` closes it at 120s; don't drop below ~90s or you cut live warm transfers (observed 71.5s).
- [Realtime tool schemas](realtime-tool-schemas.md) — **read before debugging "the agent won't call the tool".** `toZod` made every property `.nullable()` but never `.optional()`, so all 15 landed in `required`; with `strict: true` the SDK rejected the model's call *before* `execute`, leaving no log, no timeline event, no HTTP request. Never set `strict: true` on a generated schema. Found by diffing a working tool against a broken one, after three wrong root causes.
- [Ticketing API contract](ticketing-api-contract.md) — `create-ticket` needs a full `(department, type, reason)` triple and cannot express "no category", so every department has an **"Other - See Description"** catch-all (`tools/otherReason.ts`) rather than a guessed one. `submit-ticket` re-derives the department server-side and defaults to 8 — a department you pass it is dropped. All free text must go through `sanitizeForSms` (GSM-7). The four `suggested*` hints are live on `submit-ticket` at **priority 0 and validated** — verify every type/reason pair against the live tables or it falls through silently, and never hint 159.
- [Ticket-creation lock](ticket-creation-lock.md) — `submitSimplifiedTicket` released its 60s lock on success only, so the retry a failure invites hit the lock that failure left behind ("Concurrent ticket creation in progress", four attempts on one call at 23:38). This is the **after-hours path** — no-IVR files through it. Release on failure, only when the claim actually succeeded.
- [Queue agents](queue-agents.md) — one line, one subject, five shared-library tools, **no transfer tool at all**. Greeting pre-empts the request for a human; confirm the callback number *before* filing. Cross-queue routing (`tools/queueRouting.ts`) means nobody is told to call back — scheduling to the HVA Hub from every queue, **except a surgery date**. Also: how to measure a queue before designing its taxonomy, and **what four live calls found that 1,400 tests did not** — a rule the model must obey in a particular order has to state the order.
- [Measurement traps](measurement-traps.md) — snapshot-vs-history (`patients_master` is a live mirror; deletes come back), zero-means-not-instrumented, floor-vs-total, accepted≠delivered, absence-in-a-log≠absence-in-the-world, and source-scanning tests that prove a line exists rather than a behaviour. **Revert the fix and confirm the test goes red.** Also: a log written *after* validation measures the validator, not the sender — and **two agents agreeing is not verification**.
- [The reason fallback leak](reason-fallback-leak.md) — the largest wrong-data population in the practice: 6,905 on 153 in dept 3 (**ours**, `detectRequestReason()` returning the first reason of the default type), **479 on 159 in dept 8 that were never transferred** — 97% of all type-34 tickets, and **theirs**, caused by the two-character keyword `er` matched with `String.includes` — plus 224 on 153 in dept 9 and 453 with nothing at all in dept 16. Invisible in a report grouped by department, because the department is right. Open: type 34 has no generic "urgent, symptom not stated" reason, which is the 4.3% the fix cannot reach.
- [Spanish is not a translation of the English cue list](queue-agents.md) — real tickets say "Reprogramación de cita", not "reprogramar": Spanish nominalises where English uses a verb, so verb-shaped cues miss the common form. **10 of a 17-line sample matched nothing.** Use stems, and fold diacritics on both sides. Same family of error as hand-listing verb tenses in English ("fax to dr" missed "faxed to Dr. Warn").
